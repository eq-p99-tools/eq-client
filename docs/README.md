Start the client normally to play and use Scripts from an already logged-in
character. Command-line automation and offline previews are optional workflows.

The in-game Help tab embeds the workbench overview and its seven linked help
articles. The [script observations guide](scripts/observations.md) is a separate
repository reference.

Custom skin authors can use the optional [skin extensions](skin-extensions.md).
