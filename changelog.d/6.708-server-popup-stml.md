### Fixed

- Server dialogs retain STML colors and table cell boundaries, including
  `tbody`, `thead`, `tfoot`, and spanning cells. Color closes restore the
  previous color. Unknown opening tags remain literal and unknown closing
  tags are ignored, following the verified native reader.
- Unsupported popup formatting and table attributes are recorded in the gap
  log using tag/attribute names without body text or attribute values. Links
  remain inert. Table columns share the available width and text wraps inside
  cells. This sizing is an approximation; native width/height solving and
  border/background drawing remain unverified.
