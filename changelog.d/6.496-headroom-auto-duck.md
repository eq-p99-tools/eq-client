- Own walking and falling moves test room above the resolved floor,
  including a stepped-up sill, and keep their frame start when it is too
  low. A refused standing move can automatically duck on the next pass.
  Return after two seconds tests the next submitted movement candidate,
  so a higher floor cannot trigger standing from the approach's clearance.
  Titanium uses Allow Auto-Stand (also imported from the installed client);
  Mac's automatic headroom posture ignores that option. Ducked room stays
  strictly above S+1.5 on Titanium and S+0.5 on Mac. Swimmers retain the
  existing exemption.
- Standing navigation routes require the same room policy, with a
  voxel-rounding guard and generation/scale-aware cache settings. A route
  that meets a headroom refusal stops with a reason. Routes do not plan
  ducking or mounting; existing navigation caches rebuild once. The
  offline select-spot mesh API now also takes the installed client.
